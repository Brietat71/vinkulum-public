# Vinkulum 0.18.1 — première publication publique

Cette livraison ouvre les sources sous Apache-2.0 pour les éléments originaux
de Vinkulum. Les modèles tiers conservent leurs licences ; les notices et les
empreintes de provenance sont ajoutées au dépôt et au paquet Python.

Le noyau numérique et les modèles témoins sont inchangés par rapport à la
0.18.0. Cette version corrige la préparation de la distribution : métadonnées,
attributions, installation publique et documentation de contribution.

Le dépôt public commence par un instantané de livraison. L'historique de
développement privé n'est pas publié. Les rapports scientifiques archivés
conservent leurs sources figées et leurs empreintes ; leurs identifiants de
commits historiques ne sont donc pas tous résolubles dans ce dépôt.

Les limites restent celles du [registre de certification](CERTIFICATION_NOYAU.md) :
le noyau entier n'est pas certifié, les 18 écarts physiques historiques restent
documentés, et les comparaisons de performances ne valent que dans leur
périmètre mesuré. Voir le [dossier de publication](PUBLICATION_PUBLIQUE.md)
pour les contrôles de cette livraison.
