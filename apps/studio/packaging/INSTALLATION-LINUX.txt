Vinkulum Studio 0.4.1 — Linux x86-64

Extract the archive, open a terminal in the extracted directory and run:
  ./Vinkulum\ Studio/Vinkulum\ Studio

Keep the executable and _internal directory together. Python, Vinkulum 0.19.0,
Qt and VTK are bundled; no Python environment or compilation is needed on the
destination machine. CAD includes OCCT 8.0.1 and build123d 0.11.1+vinkulum.occt8.
The CAD button opens primitives, extrusions, booleans, fillets and STEP exchange.
One solid per part; CAD projects retain the BREP and SI mass properties.

The target platform is Linux x86-64, glibc 2.39 (Ubuntu 24.04), X11 and Mesa
OpenGL. Consult check/bundle-check.json and build-info.json for this build's
qualification. Older glibc, Linux ARM64 and native Wayland are not qualified.
A Wayland session must provide XWayland. The system supplies its graphics
libraries and OpenGL driver. Ubuntu 24.04 Qt/X11 dependencies include:
  libegl1 libgl1 libgl1-mesa-dri libxkbcommon-x11-0 libxcb-cursor0
  libxcb-icccm4 libxcb-keysyms1 libxcb-image0 libxcb-render-util0 libxcb-util1
To select XWayland explicitly:
  QT_QPA_PLATFORM=xcb ./Vinkulum\ Studio/Vinkulum\ Studio

Optional standalone check, from a graphical session:
  ./Vinkulum\ Studio/Vinkulum\ Studio --bundle-check ./verification
This runs a double pendulum and generates a report and 3D capture. It also
checks a perforated CAD part and its STEP round-trip with OCCT 8. This
packaging check does not certify arbitrary mechanical trajectories.

The English interface offers Model, Simulate and Inspect workspaces, light
and graphite themes, a command palette (Ctrl+K), and comparisons of captured
runs on their native samples. This is experimental research software.

changes. Original code is Apache-2.0. See Licences/ and _internal/ for dependency
